# 애드센스 수익형 웹사이트 분야 조사 (2026-09)

> 목적: 구글 애드센스(사이트에 광고를 붙여 클릭·노출당 돈을 받는 구글 광고 프로그램)로 수익을 내기 좋은 분야 20개를 고르고, 벤치마킹 사이트와 차별화 포인트를 정리한다.
> 배포 전제: 정적 사이트(서버 없이 HTML/CSS/JS만) → Cloudflare Pages + 개인 도메인.

## 0. 결론 3줄

1. **한국 트래픽은 단가가 낮다**(평균 CPC 약 $0.1, 한국 블로그 Page RPM 1,500~10,000원). 그래서 (A) 국내는 **금융·세금·보험·자동차 같은 고단가 분야**를 노리고, (B) 트래픽형 도구는 **영어판을 같이 만들어 미국·영국 방문자**를 받아야 한다.
2. 가장 검증된 모델은 **"계산기·변환기 같은 단일 목적 도구 + 설명 글"** 이다. calculator.net 월 2,800만, ilovepdf 월 2.26억, wordcounter.net 월 1,400만, remove.bg 월 7,900만 방문.
3. 2026년 애드센스 심사는 **"도구만 있고 설명이 없는 사이트"를 저품질(Low value content)로 거절**한다. 도구마다 사용법·계산 근거·FAQ 글을 붙이고, 소개·개인정보처리방침·문의 페이지 3종을 반드시 넣는다. `*.pages.dev` 무료 주소는 승인이 안 되므로 개인 도메인이 필수다.

## 1. 수익 구조 핵심 (조사 근거)

| 항목 | 내용 |
|---|---|
| 수익 공식 | 방문수 × 클릭률(CTR) × 클릭단가(CPC). 키워드(분야)가 단가를 결정 |
| 고단가 분야 (Tier-1 기준 RPM) | 금융·은행 $65~110, SaaS $40~70, 법률 $30~55, 헬스케어 $25~45, 보안 $22~38 |
| 저단가 분야 | 연예·가십 $1~3, 레시피 $2~5, 스포츠 뉴스 $2~5, 일반 라이프스타일 $2~6 |
| 한국 고단가 키워드 | 보험(자동차보험·어린이보험), 대출(주담대 갈아타기·전세대출), 주식거래, 부동산, 법률(교통사고 합의·이혼 상담), 세금 |
| 한국 단가 수준 | 평균 CPC 약 $0.1 (Tier 4 분류), 블로그 Page RPM 1,500~10,000원 |
| 심사 기간 | 보통 며칠~2-4주. 거절 사유 1위는 "저품질 콘텐츠" |

**RPM**(1,000회 노출당 수익), **CPC**(클릭 1회당 단가) — 아래 표에서 계속 쓰는 용어.
