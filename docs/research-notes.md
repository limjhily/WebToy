# 시장조사 원본 노트 (2026-09-08)

각 분야별로 ① 기존 사이트 현황 ② 사용자가 실제로 원하는 것(기사·커뮤니티·제도 변화) ③ 그로부터 도출한 차별화 기능을 기록한다.
차별화의 기준은 "정보는 존재하지만 흩어져 있거나 묻혀 있어서, 사용자가 결정할 때 필요한 항목을 전면에 배치한다"이다. (청약달력의 전세가능·실거주의무 노출 방식)

---

## 1. 직장인 급여·세금

**기존 사이트**: 사람인, 인크루트, 잡코리아, 시그널플래너, 코스모스팜(연봉탐색기), 계산플러스
공통점: 전부 **"연봉 입력 → 실수령액 출력" 단방향**. 표는 있지만 시뮬레이션이 없다.

**사용자가 원하는 것** (잡플래닛 직장인 764명 조사, 2026)
- 2026 중위 연봉인상률 5%. "4~6%" 31.7%, "1~3%" 23.9%
- 연봉 협상 "일방 통보" 68% vs "협상 절차" 28%. 조정 신청자의 48%가 인상 성공
- 성과급 받은 사람 30%, 그중 35.4%가 100~300만 원 구간
- 검색 의도는 "내 연봉이 얼마인지"가 아니라 **"올려 받으면 실제로 얼마가 더 들어오는지"**

**차별화 기능**
1. **인상 시뮬레이션**: 연봉 인상액을 넣으면 월 실수령이 얼마 늘어나는지. 과세 구간을 넘으면 체감 인상률이 떨어지는 지점을 붉게 표시 ("연봉 500만 원 올랐는데 월 실수령은 32만 원만 늘어남")
2. **역산 계산기**: "월 실수령 300만 원 받으려면 연봉 얼마?" — 기존 사이트에 거의 없음
3. **성과급 실수령 계산기**: 성과급은 원천징수 방식이 급여와 달라 헷갈림. 받는 사람의 3분의 1이 관심
4. **현직 vs 이직 제안 나란히 비교**: 연봉·비과세·복지·퇴직금 포함 여부까지 넣어 실수령 차액 표시
5. 연봉 협상 시점(1~3월)에 맞춘 가이드 글

## 2. 대출·부동산

**기존 사이트**: 부동산계산기.com(사실상 1위, 기능 종류는 가장 많음), 계산기24, 아는자산, 네이버 부동산, 뱅크샐러드
공통점: 계산기 종류는 많으나 **규제 변화가 반영이 느리고, 판단(=결정)을 도와주지 않는다.**

**사용자가 원하는 것**
- **스트레스 DSR 3단계** 시행(2025.7~). 연소득 1억 기준 한도가 시행 전 대비 1억 2천만 원 감소
- **지방 주담대는 2026.1.2~6.30 한 단계 낮은 2단계 유예 적용** → 지역·시기에 따라 한도가 다름. 이걸 반영한 계산기가 거의 없다
- 1금융 DSR 40%, 2금융 50%
- 갈아타기 판단 기준은 금리 차이가 아니라 **"절감 이자 − 중도상환수수료 − 부대비용"**. 중도상환수수료 약 0.6%, 3년 경과 시 면제. 부대비용은 근저당 설정비·감정평가 수수료·인지세

**차별화 기능**
1. **갈아타기 손익분기점 계산기**: "몇 개월을 더 보유해야 갈아타기가 이득으로 전환되는지"를 그래프와 개월 수로 표시. 기존 사이트는 이자 차액만 보여줌
2. **지역·시기 자동 반영 DSR 한도**: 수도권/지방, 1금융/2금융, 유예 기간 여부를 고르면 스트레스 금리가 자동 적용
3. **부대비용 체크리스트 내장**: 근저당 설정비·감정평가·인지세·법무사비를 기본 항목으로 넣어 총비용으로 계산
4. 규제 변경 이력 페이지 (언제 무엇이 바뀌었는지) — 검색 유입이 큰 롱테일

## 3. 투자·절세

**기존 사이트**: omnicalculator, 뱅크샐러드, 각 증권사 계산기
공통점: 단순 복리 계산은 많지만 **세금을 반영한 세후 수익 비교가 없다.**

**사용자가 원하는 것**
- 2026 세제개편안: ISA 개편(일반 ISA 혜택 축소 + 국내 투자 전용 "생산적금융 ISA" 신설) — **아직 정부안이며 국회 심의 중**
- ISA 연 납입 한도 4,000만 원, 비과세 한도 일반형 500만 원 / 서민형 1,000만 원
- 연금계좌 세액공제율: 총급여 5,500만 원 이하 16.5%, 초과 13.2%. 최대 환급 약 148만 원
- ISA 만기 자금을 60일 내 연금계좌로 이전하면 10%(최대 300만 원) 추가 세액공제
- 일반계좌 15.4% vs ISA 초과분 9.9% 분리과세, ISA는 손익통산 가능

**차별화 기능**
1. **연말정산 환급 역산기**: "IRP·연금저축에 얼마를 더 넣으면 얼마를 돌려받나"를 월 단위로. 12월에 검색량이 폭증하는 키워드
2. **계좌별 세후 수익 비교**: 같은 수익률을 일반계좌 / ISA / 연금계좌에 넣었을 때 세후 최종 금액을 나란히
3. **제도 개편 전후 비교 토글**: 개편안이 확정되면 "현행 vs 개편안" 두 결과를 동시에 표시. 확정 전까지는 정부안임을 명시
4. ISA→연금 이전 추가공제 계산 (거의 아무도 계산기로 안 만들어 둠)

## 4. 보험·연금

**기존 사이트**: 국민연금공단 모의계산, 보험다모아, 중앙노후준비지원센터
가장 큰 약점: **공동인증서 로그인 벽**. "공단 홈페이지에 들어갔다가 로그인 화면 보고 그냥 창을 닫는" 사용자가 많다는 언급이 반복됨. 인증 없는 모의계산이 있지만 찾기 어렵고 UI가 낡음.

**사용자가 원하는 것**
- 2026 연금개혁(1988년 제도 도입 이후 27년 만의 대규모 개편): 보험료율 9% → 2026년 9.5% → 2033년 13%. 소득대체율 41.5% → 43%
- "더 내고 더 받는" 구조라는데 **나에게 유리한지 불리한지**를 알고 싶어 함
- 기초연금 대상 여부, 실비 청구 절차

**차별화 기능**
1. **로그인 없는 예상연금 계산 + 개혁 반영**: 생년월일·가입기간·평균소득만 넣으면 결과. 공단 사이트의 가장 큰 진입장벽 제거
2. **개혁 전 vs 후 내 연금 비교**: 내가 더 내는 돈 총액과 더 받는 돈 총액을 나란히. 이 비교를 해주는 곳이 사실상 없음
3. **손익분기 나이 표시**: "몇 살까지 살면 낸 돈을 회수하는가" — 가장 궁금해하는 지점
4. 광고 단가가 국내 최고 구간(보험)이라 트래픽이 적어도 수익성이 높음

## 5. 자영업·사업자

**기존 사이트**: 홈택스(2026 리뉴얼, 미리채움 서비스), 삼쩜삼, 헬프미·흠택스 등 세무 대행
**사용자가 원하는 것**
- 세무사 비용 부담: 신고 수수료 20만 원(+VAT), 월 기장료 7~30만 원 별도
- 신고 일정이 흩어져 있음: 부가세 1월·7월, 종합소득세 5월, 중간예납 11월 30일
- 2026 부가세 신고 기한은 휴일 연장으로 7월 27일 같은 예외가 있어 놓치기 쉬움

**차별화 기능**
1. **내 세금 캘린더 자동 생성**: 업종·과세유형(일반/간이)·법인 여부를 고르면 올해 내 신고·납부일이 전부 나오고 구글 캘린더(.ics)로 내보내기. 공휴일 연장까지 반영
2. **세무사 위탁 vs 셀프 신고 비용 비교**: 매출 규모를 넣으면 기장료 총액과 셀프 신고 시 절감액, 그리고 셀프가 위험해지는 매출 기준선 표시
3. **인쇄·납품 견적 계산기**: 운영 경험 기반. 수량·용지·후가공으로 단가 계산. 세계적으로도 드문 도구이며 E-E-A-T(경험·전문성) 근거가 됨
4. 사업자번호 유효성 검증, 세금계산서 마감일 알림
